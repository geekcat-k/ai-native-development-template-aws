# Phase 1-2: 要件定義・非機能要件プロンプト

このリポジトリのREADME.mdとAGENTS.mdを守ってください。

今回は要件定義と非機能要件の整理だけを行います。設計や実装には進まないでください。

参照するドキュメント:

- `docs/00-project-brief.md`
- `docs/01-requirements.md`
- `docs/02-non-functional-requirements.md`

以下を整理してください。

## 機能要件

各機能について、次を定義してください。

- ID
- 機能名
- 概要
- 利用者
- 入力
- 処理
- 出力
- 正常系
- 異常系
- 権限
- 受け入れ条件

## 非機能要件

少なくとも次を確認してください。

- 性能
- 可用性
- セキュリティ
- 認証・認可
- バックアップ
- ログ
- 監視
- データ保持
- スケーラビリティ
- メンテナンス性
- コスト
- 対応環境

最後に、確定事項、仮定、未決定事項、確認したい事項を分け、基本設計へ進んでよいか承認を求めてください。
