# Phase 8: レビュープロンプト

このリポジトリのREADME.mdとAGENTS.mdを守ってください。

今回はレビューだけを行ってください。指示があるまで修正は行わないでください。

レビュー対象:

- Pull Requestまたは変更差分
- 関連するtasks
- 関連するdocs

レビューでは、次を優先してください。

- 要件との整合性
- 受け入れ条件の達成
- 仕様漏れ
- 破壊的変更
- セキュリティリスク
- データ損失リスク
- テスト不足
- 運用上の懸念

出力形式:

1. 重大な指摘
2. 中程度の指摘
3. 軽微な指摘
4. テスト不足
5. 確認したいこと
6. 総評

問題がない場合は、その旨と残るリスクを明示してください。
